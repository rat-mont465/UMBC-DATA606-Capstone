# Documentation & Project Presentations

This directory houses the comprehensive documentation, professional credentials, and milestone presentations associated with the Multimodal Brain Tumor (Glioma) Segmentation and Clinical Prognosis capstone project. 

## Featured / Most Up-to-Date Documents
For evaluators, reviewers, or casual visitors looking for the definitive, final state of this project, the following three documents represent the primary and most current assets:
1. **`Multimodal Brain Tumor Risk and Variable Assessment_Final.pptx`**: The comprehensive final slide deck detailing the complete pipeline, models, and quantitative evaluations.
2. **`report.md`**: The exhaustive written design document covering architecture, empirical findings, limitations, key achievements, and video presentation links.
3. **`Resume.md`**: The professionally updated career portfolio document incorporating recent data science credentials.
