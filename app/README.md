# Streamlit Application & Web Interface

This directory contains the code for the web-based application designed to streamline the usage of the capstone project models for casual users.

## Key Overview & Purpose
* **User-Friendly Interface:** Built using **Streamlit** to provide an accessible web interface, abstracting away complex command-line execution for non-technical or casual users.
* **Core Outputs:** Designed to deliver visual 3D tumor segmentation overlays alongside prognosis and survivability projections in under 30 minutes.
* **Prerequisites & Workflow:** Because this app relies on the trained model checkpoints and feature pipelines generated by the core workflow, **the main notebook and training pipeline must be run first** to populate the necessary model weights and artifacts.

## Input Requirements
To run properly, the application expects:
1. **4 MRI Image Modalities:** Standard multi-modal neuroimaging inputs (FLAIR, T1, T1CE, and T2) in NIfTI format.
2. **Clinical Metadata:** Associated patient metadata required by the downstream prognostic and survival models.

## Environment & Dependencies
* This application utilizes the exact same environment configuration specified in the notebooks directory (`melonma_environment.yml`). 
* To launch the app, ensure your environment is active and run:
  ```bash
  streamlit run brain_tumor_app.py
  ```

## Current Status & Limitations
* **Crucial Notice:** This application is currently **unfinished outside of the segmentation portion**. While the visualization and interactive segmentation components are operational, downstream prognosis and survivability prediction features are still under active development or awaiting final integration.
