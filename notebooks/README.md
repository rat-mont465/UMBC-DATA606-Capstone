# Notebooks & Implementation Workflow

This directory contains the exploratory data analysis, segmentation model training/validation, feature extraction + selection, and survivability + prognosis training/validation code for this capstone project.

This code can be read directly without prior understanding through headers and comments. This code was executed on a home laptop, therefore the requirements are deemed to be reasonable for individuals.

## Important Disclaimers & Status
* **AI Assistance Acknowledgment:** Artificial intelligence tools (such as large language models) were utilized to assist during the development, debugging, and refinement of this code and documentation.
* **Code Completion Status:** This code is fully finished and operational end-to-end, with the exception of one minor visualization figure that does not impact the function and veracity of the models.
* **Data Dependency:** The scripts in this directory require the source datasets and mapping files detailed in the `/data` directory to be set up locally before execution.

## Directory Contents
1. **`Tumor_Segmentation_Prognosis_Prediction.ipynb`**: The main executable notebook containing all of the code with the exception of the app.
2. **`system_requirements.md`**: A dedicated specification file detailing the software environment, dependency versions, and recommended hardware setup for running the pipeline.
